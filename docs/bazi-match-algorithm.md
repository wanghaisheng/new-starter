# 八字匹配算法说明文档

## 一、算法目标

本算法用于根据用户八字（生辰八字）信息，结合五行、纳音、生肖等命理规则，计算两人之间的匹配分数（0-100），为配对、推荐、婚恋等场景提供科学、可解释的合婚依据。

---

## 二、核心原理

### 1. 五行生克（天干地支）
- 每柱天干、地支分别映射为五行（金、木、水、火、土）。
- 天干、地支两两比对：
  - 相生加分（如木生火）
  - 相克扣分（如木克土）
  - 同五行小加分
- 男女互补（如男天干生女天干、女地支生男地支）加权更高。

### 2. 纳音五行（60甲子）
- 每柱天干地支组合（如“甲子”、“乙丑”）映射为独立的纳音五行（金木水火土）。
- 纳音五行之间也进行生克加分/扣分，进一步细化命理合婚。

### 3. 生肖刑冲合害
- 每柱地支两两比对，涵盖所有传统生肖关系：
  - **三合**（如申子辰合水）：极佳组合，大加分。
  - **六合**（如子丑）：良好组合，加分。
  - **三刑**（如寅巳申）：有刑，扣分。
  - **六冲**（如子午）：冲突，扣分。
  - **六害**（如子未）：有害，小扣分。
  - **合**（如子与丑）：加分。
- 每种关系可单独设置权重（如 sanhe、liuhe、zodiac），灵活适配不同流派。

### 4. 评分归一化
- 所有加分项、扣分项累加，最终分数归一化到 0-100，便于排序与推荐。

### 5. 可扩展性
- 可扩展更多命理规则，如十神、空亡、男女年柱互补等。
- 可输出详细每柱评分解释，便于用户理解推荐理由。

---

## 三、算法流程

1. **解析八字**：将用户八字字符串（8字）拆分为4柱（年、月、日、时），每柱包含天干和地支。
2. **映射五行**：天干、地支、纳音分别映射为五行。
3. **五行生克评分**：天干、地支、纳音五行分别比对，生加分、克扣分、同五行小加分。
4. **生肖关系评分**：地支两两比对，按三合、六合、三刑、六冲、六害、合等规则加权。
5. **权重调整**：每项加分/扣分均可自定义权重。
6. **分数归一化**：最终分数限制在0-100之间。

---

## 四、权重参数（可调）
- sheng（五行相生加分，默认15）
- ke（五行相克扣分，默认-10）
- same（同五行小加分，默认8）
- nayin（纳音五行生加分，默认10）
- zodiac（生肖合/冲/害/刑基础权重，默认12）
- sanhe（三合加分，默认16）
- liuhe（六合加分，默认14）

## 五、典型调用示例

```typescript
const score = matchService.baziMatchFull(
  userA.profile, userB.profile,
  {
    genderA: '男',
    genderB: '女',
    weights: {
      sheng: 18, ke: -12, same: 8, nayin: 12,
      zodiac: 10, sanhe: 20, liuhe: 15
    }
  }
);
// score 为全维度八字/生肖合婚匹配分
```

## 六、规则表（部分）

### 1. 五行生克
- 木生火、火生土、土生金、金生水、水生木
- 木克土、土克水、水克火、火克金、金克木

### 2. 纳音五行（60甲子）
- 甲子、乙丑：海中金
- 丙寅、丁卯：炉中火
- 戊辰、己巳：大林木
- ...（详见代码 jiaziList/nayinArr）

### 3. 生肖关系
- 三合：申子辰、巳酉丑、寅午戌、亥卯未
- 六合：子丑、寅亥、卯戌、辰酉、巳申、午未
- 三刑：寅巳申、丑戌未、子卯刑
- 六冲：子午、丑未、寅申、卯酉、辰戌、巳亥
- 六害：子未、丑午、寅巳、卯辰、申亥、酉戌
