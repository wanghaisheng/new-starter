# 后端账号删除开发任务

## 目标
为移动端设置页等相关页面提供真实账号删除的后端 service/repository 支撑，替换现有 mock 实现，实现用户自主注销账号功能。

## 子任务拆解
1. 设计 AccountDeletionService/Repository 接口，明确账号删除流程与安全校验机制。
2. 实现账号删除、注销申请、二次确认等核心接口。
3. 支持数据清理、依赖关系处理（如消息、配对等）。
4. 编写自动化测试用例，覆盖主要账号删除场景。
5. 配合前端联调，修复集成问题。
6. 完善接口文档，便于后续维护。

## 验收标准
- 支持用户自主发起账号删除，流程安全合规。
- 前后端联调通过，用户可正常注销账号。
- 相关接口有详细文档和测试。
