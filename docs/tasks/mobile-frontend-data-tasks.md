# 移动端前端和数据开发任务计划

## 概述

本文档定义了移动端前端和数据开发相关的任务，基于对原型(prototype.html)与当前实现的对比分析，以及项目README.md中的技术要求。开发将分为三个环境阶段：

1. **Mock阶段**：使用JSON+fake IndexedDB模拟数据
2. **Local阶段**：使用本地IndexedDB存储
3. **Production阶段**：使用Firebase+IndexedDB实现在线/离线数据同步

## 1. 原型与现有实现对比分析

### 1.1 已实现的功能

- 基本的页面路由结构 (`app/mobile/`目录)
- 底部导航栏组件 (BottomNavBar)
- 卡片滑动组件 (SwipeCard, CardStack)
- 消息列表和聊天界面基础组件
- 用户资料页面基础结构

### 1.2 需要完善的功能

- **匹配界面**：实现匹配成功的动画和交互
- **聊天功能**：完善实时聊天和消息通知
- **发现页面**：优化卡片滑动体验和用户信息展示
- **UI美化**：实现原型中的玻璃卡片效果和渐变背景

### 1.3 图片资源需求

- 用户头像图片 (从randomuser.me和unsplash.com)

- 背景图片和占位图

## 4. 数据库配置与实现任务

### 任务4.1：配置Mock环境（JSON+fake IndexedDB）

**描述**：配置开发环境使用JSON文件作为主数据源，fake-indexeddb模拟客户端离线存储

**步骤**：
1. 更新`.env.development`配置：
   ```
   NEXT_PUBLIC_DATABASE_ENV=mock
   NEXT_PUBLIC_MOCK_DB_TYPE=json
   NEXT_PUBLIC_USE_FAKE_INDEXEDDB=true
   NEXT_PUBLIC_MOCK_DB_JSON_PATH=./data/mock-db.json
   NEXT_PUBLIC_MOCK_DB_AUTOSAVE=true
   ```
2. 创建或更新`data/mock-db.json`文件，添加测试数据
3. 确保`MockDatabaseClient`和`MockIndexedDBClient`正确配置

**完成标准**：
- 应用启动时正确加载JSON数据
- 数据变更自动保存到JSON文件
- fake-indexeddb正确模拟客户端离线存储

### 任务4.4：配置Local环境（IndexedDB）

**描述**：配置本地开发环境使用IndexedDB作为主要存储

**步骤**：
1. 创建`.env.local`配置：
   ```
   NEXT_PUBLIC_DATABASE_ENV=local
   NEXT_PUBLIC_LOCAL_DB_TYPE=indexeddb
   NEXT_PUBLIC_DB_NAME=app_database_local
   NEXT_PUBLIC_DB_VERSION=1
   ```
2. 确保`IndexedDBClient`正确配置
3. 实现数据迁移脚本，从mock数据迁移到IndexedDB

**完成标准**：
- 应用可以使用IndexedDB存储和检索数据
- 数据迁移脚本正常工作

### 任务4.5：配置Production环境（Firebase+IndexedDB）

**描述**：配置生产环境使用Firebase作为远程数据源，IndexedDB作为离线存储

**步骤**：
1. 创建或更新`.env.production`配置：
   ```
   NEXT_PUBLIC_DATABASE_ENV=production
   NEXT_PUBLIC_CLOUD_DB_TYPE=firebase
   NEXT_PUBLIC_USE_FIREBASE=true
   NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
   NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
   NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
   NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_messaging_sender_id
   NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
   ```
2. 确保`FirebaseClient`正确配置
3. 实现在线/离线数据同步机制

**完成标准**：
- 应用可以连接到Firebase并同步数据
- 离线时可以使用IndexedDB继续工作
- 恢复在线时自动同步数据

## 总结

本任务计划涵盖了移动端前端和数据开发的各个方面，从UI组件开发到数据库配置，从页面实现到测试优化。通过分阶段实施，可以确保开发过程有序进行，并在每个阶段都有可交付的成果。

开发过程将遵循README.md中描述的数据存储策略：
- **Mock阶段**：使用JSON文件作为主数据源，fake-indexeddb模拟客户端离线存储
- **Local阶段**：使用IndexedDB作为主要存储
- **Production阶段**：使用Firebase作为远程数据源，IndexedDB作为离线存储

通过这种分层存储架构，可以确保应用在各种网络条件下都能正常工作，并提供良好的用户体验。
