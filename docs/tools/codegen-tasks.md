# 自动生成工具集成与优化任务清单

## 一、目标与背景

为提升开发效率、统一团队风格、减少重复劳动，需集成和规范自动代码生成工具（如 Plop.js），实现 hooks、组件、service、adapter、测试用例等一键生成，适配 Next.js 15/TypeScript 现代项目体系。

---

## 二、任务清单

### 1. 工具选型与基础集成
- [x] 推荐主力工具：Plop.js（社区活跃、bug 少、Next.js 兼容性好）
- [ ] 在项目根目录集成 plop，配置 plopfile.js
- [ ] 新建 plop-templates 目录，存放 hooks、组件、service、adapter、test 等模板文件
- [ ] 在 package.json 增加 plop 相关命令脚本

### 2. 模板与生成规范
- [ ] 设计并完善基础 hooks、业务 hooks、组件、service、adapter 等模板，支持参数化生成
- [ ] 模板需包含 loading/error/empty、服务注入、异常处理、类型定义等规范内容
- [ ] 支持自动生成测试用例、README 示例、类型定义等
- [ ] 支持目录结构自定义和自动导入

### 3. 高级集成与扩展
- [ ] 支持多类型模板（如单实体、列表、事件型 hooks）
- [ ] 支持多语言、自动文档生成、A/B 测试等高级能力的模板扩展
- [ ] 集成到 CI/CD 流程，保障新建模块规范化
- [ ] 支持 VSCode/JetBrains 插件辅助生成

### 4. 团队协作与知识传承
- [ ] 编写《代码生成工具使用手册》，同步最佳实践到 docs/tools/codegen-tasks.md
- [ ] 定期评审和升级模板，适配架构演进和新业务需求
- [ ] 鼓励新成员优先使用模板生成主流程代码

---

## 三、预期收益
- 大幅提升开发效率，降低重复劳动和出错率
- 团队风格统一，协作与知识传承无障碍
- 模板升级后全员受益，适配产品从 0-1 到 10-100 的演进
