### Firebase 客户端标准化

已完成 Firebase 客户端的全面标准化，包括：

   - 创建了清晰的目录结构，将主客户端与辅助功能分离

   - 添加了 `index.ts` 导出文件和完整的 `README.md` 文档

2. **特定功能模块化**:
   - 实现了 `FirebaseQueryBuilder` 类，优化查询构建过程

3. **错误处理和日志**:

   - 确保所有方法都包含适当的错误捕获和处理

4. **接口和类型**:
   - 确保正确继承 `BaseClient` 并实现 `IDatabaseClient` 接口
   - 标准化 `FirebaseConfig` 接口并继承 `DatabaseConfig`
   - 优化类型定义，提高类型安全性

5. **功能扩展**:
   - 增强了查询功能，支持复杂过滤和排序
   - 优化了批量操作，支持大规模数据处理
