# 消息服务适配器说明

本目录包含相亲/社交类应用的消息服务适配器，所有适配器均实现统一接口 `IMessageService`，专注于数据聚合、同步、过滤，不承载复杂业务逻辑。

## 适配器一览

| 适配器                             | 场景               | 特点与说明                                             |
|------------------------------------|--------------------|------------------------------------------------------|
| MockMessageServiceAdapter          | 本地开发/测试/离线 | 纯内存，支持全部基础能力，适合离线和测试               |
| RemoteMessageServiceAdapter        | 云端/生产/多端同步 | 通过 RESTful API/WebSocket 远程操作，需后端配合         |
| HybridMessageServiceAdapter        | 移动端/弱网/同步   | 本地优先、远程兜底，写操作本地优先、远程异步同步         |
| AdvancedHybridMessageServiceAdapter| 复杂/高可用生产环境 | 依赖统一数据服务，支持多级缓存、离线队列、自动同步等     |

## 主要功能
- **消息增删改查**：支持文本、图片等富媒体消息的发送、更新、删除、撤回、批量操作
- **分页与历史查询**：支持会话消息分页、历史消息拉取
- **消息变更监听**：所有适配器支持 onMessageChange，便于 UI 实时刷新
- **离线与同步**：Hybrid/AdvancedHybrid 支持离线缓存、弱网可用、自动同步
- **多端推送/同步**：Remote/Hybrid 支持多端消息同步与推送（需后端支持）
- **事件扩展**：部分适配器支持网络状态、同步进度等事件监听

## 架构设计原则
- **分层解耦**：适配器层仅做数据聚合/同步/过滤，复杂业务（如智能推荐、内容审核）由业务/AI 层实现
- **接口统一**：所有适配器实现 IMessageService，便于切换和扩展
- **可插拔**：可根据实际场景灵活组合 mock、本地、远程、hybrid 等多种实现

## 推荐使用场景
- **开发/测试**：MockMessageServiceAdapter
- **生产/云端**：RemoteMessageServiceAdapter + Hybrid/AdvancedHybrid 组合，兼顾离线与同步
- **高可用/复杂业务**：AdvancedHybridMessageServiceAdapter，结合统一数据服务实现多级缓存与自动同步

## 扩展建议
- 如需语音、视频、阅后即焚等新消息类型，仅需扩展 Message 类型和适配器聚合逻辑
- 安全/审核/AI排序等复杂逻辑建议在业务/AI 层实现，适配器层只做数据搬运和聚合
- 推送/订阅能力建议由 Remote/Hybrid 层结合 WebSocket/SSE 实现

### 品牌适配器创意示例

- **BrandA/BrandBMessageServiceAdapter**：可针对不同品牌的消息内容、过滤规则、通知机制等做定制，实现品牌差异化运营。
- **VIP 专属消息适配器**：为 VIP 用户提供专属消息通道、优先推送、专属表情等。
- **高隐私适配器**：支持阅后即焚、匿名聊天、自动加密等隐私保护能力。
- **青少年安全适配器**：增强内容审核、反骚扰、反诈骗，限制夜间消息等。
- **国际化适配器**：自动翻译消息内容，支持多语言和本地化表情。
- **活动/节日主题适配器**：节日自动推送祝福、主题表情，支持群发活动消息。
- **企业/红娘服务适配器**：支持红娘/客服介入，插入官方提示、服务提醒。
- **极速适配器**：针对低端机/弱网环境，优化消息体积与同步策略。
- **多端同步适配器**：支持 Web/APP/小程序跨端已读、推送、草稿同步。
- **AI 智能助手适配器**：集成机器人、智能回复、情感分析等功能。

Hybrid+品牌适配器组合：如需多品牌聚合，可通过 Hybrid/AdvancedHybrid 组合不同品牌适配器，灵活切换或并行支持多品牌消息流。

多端体验优化：品牌适配器可根据端能力（如小程序、APP、Web）做本地缓存、推送、富媒体等能力适配，提升响应速度和用户体验。
