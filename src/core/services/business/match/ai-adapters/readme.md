# AI Adapter 匹配算法设计与创新

本目录用于存放和维护交友匹配服务的核心算法实现。我们坚持“我们和别人不一样”的理念，持续探索与众不同、激发新鲜感和成长的匹配机制。

---

## 已实现算法

- **地理位置匹配**：基于经纬度距离筛选。
- **标签/兴趣匹配**：支持 includeTags/excludeTags 灵活组合。
- **MBTI 匹配**：支持人格类型完全一致与互补加分。
- **八字命理匹配**：全量与简化五行算法，支持权重。
- **手机品牌匹配**：可按授权或主动选择品牌筛选。
- **城市匹配**：支持地理授权和页面筛选。
- **随机匹配**：兜底推荐。
- **多机制综合匹配**：可任意组合上述条件，支持扩展。

## 创新与差异化匹配算法（理念与方向）

### 1. 互补型/反差型匹配
- **极致互补**：
  - 设计多维度（性格、兴趣、作息、消费观、能力等）互补度量。
  - 算法：为每个维度定义互补映射表（如 E/I、早/晚、理性/感性），得分越“反差”越高。
  - 应用：主动推荐与自己“最不一样”的人，激发新鲜感。
- **反差标签**：
  - 系统自动识别用户标签中的“对立”或“稀有组合”，如“内向+外向”、“文艺+理工”。
  - 可设定“反差优先”开关，用户可选择体验。

### 2. 成长型/挑战型匹配
- **成长目标互补**：
  - 用户可设置成长目标（如“提升英语”、“健身打卡”）。
  - 算法：推荐该领域已达成目标、或愿意共同成长的用户。
  - 应用：组队互助、经验传递、目标陪伴。
- **挑战型匹配**：
  - 系统定期推送“挑战对象”，如“本周挑战：和完全不同专业/家乡/兴趣的用户交流”。
  - 可结合 gamification，完成挑战可获得勋章、积分。

### 3. 观点碰撞/辩论匹配
- **观点对立匹配**：
  - 通过问卷、动态、标签等，识别在某些社会/文化/兴趣话题上观点对立的用户。
  - 算法：为每个话题构建观点向量，推荐异向用户。
  - 应用：理性讨论区、观点碰撞房间。
- **辩论/话题挑战**：
  - 系统定期设定辩题，自动配对正反双方。
  - 用户可报名参与，系统根据历史观点自动分组。

### 4. 生活方式差异匹配
- **生活节奏反差**：
  - 采集用户作息、出行、消费等生活节奏数据。
  - 算法：优先推荐与自己节奏明显不同的用户。
- **兴趣冷门/小众优先**：
  - 识别兴趣标签的稀有度，优先推荐小众兴趣用户。

### 5. 命运随机/命中注定匹配
- **今日命运之轮**：
  - 每日随机配对，双方只能通过限定话题或小游戏互动。
  - 增加神秘感和趣味性。
- **命理极端不合型**：
  - 利用八字/星座等算法，推荐系统判定为“最不可能合拍”的人。
  - 鼓励用户尝试“命运之外”的缘分。

### 6. 社交圈突破/弱关系匹配
- **社交圈突破**：
  - 利用社交网络数据，主动推荐与自己完全无交集的用户。
  - 算法：排除共同好友、学校、公司、家乡等。
- **弱关系优先**：
  - 推荐“朋友的朋友的朋友”，弱连接带来新机会。

### 7. 动态情绪/当下状态匹配
- **情绪互补**：
  - 用户可主动上报或系统识别当日心情（如“低落”、“兴奋”）。
  - 推荐情绪互补或能带来正向影响的用户。
- **当下动态驱动**：
  - 如“刚完成挑战”、“正在旅行”，即时匹配同样状态的用户。

### 8. 价值观底线反向过滤
- **底线冲突优先**：
  - 识别用户在某些底线问题（如“环保”、“诚信”等）上的立场。
  - 有意识地推荐底线不同的用户，鼓励理性碰撞与包容力提升。

### 9. 共同反感/禁忌型匹配
- **共同“讨厌/反感/不能接受”匹配**：
  - 用户可主动选择自己“绝对不能接受”或极度反感的事物（如“臭豆腐”、“榴莲”、“出门旅行不规划”等）。
  - 算法：优先推荐在这些禁忌/反感项上高度一致的用户，减少潜在冲突，提升默契。
  - 应用：适合“底线清晰”、“生活习惯敏感”用户，提升相处舒适度。
  - 可扩展为“反感雷达”模式，匹配时高亮双方共同雷区，避免误踩。

### 10. 榜单刷榜型匹配
- **你爱刷的榜单匹配**：
  - 用户可选择/上传自己热衷刷的榜单，如“奥斯卡电影”、“豆瓣Top250”、“必去景点”、“年度热歌”等。
  - 算法：根据榜单重合度、喜好交集、刷榜进度等，优先推荐榜单兴趣高度重合或互补的用户。
  - 应用：适合“榜单控”、“成就型”、“话题型”用户，促进共同打卡、交流观影/体验心得。
  - 可扩展为“榜单挑战”或“组队刷榜”模式，提升互动趣味。

### 11. 人生阶段/节点共鸣匹配
- 用户标记自己正处于的人生阶段（如“刚毕业”、“裸辞gap”、“准备考研”、“创业中”、“初为人母”等）。
- 匹配处于同一阶段或刚经历过该阶段的用户，便于共鸣、经验互助。

### 12. 遗憾清单互补匹配
- 用户填写“我的人生遗憾清单”或“想做但没做的事”。
- 匹配已经完成这些事项、或同样有此遗憾、愿意一起弥补遗憾的人。

### 13. 小确幸共鸣匹配
- 用户记录/打卡“让自己开心的小事”（如“下雨天喝热茶”、“猫咪陪伴”、“深夜撸串”）。
- 匹配在“小确幸”类型上高度重合的用户，分享生活美好。

### 14. 尴尬瞬间共情匹配
- 用户匿名分享自己最尴尬的经历。
- 匹配有类似经历或能共情的用户，促进真实和治愈式交流。

### 15. 语音/口音/方言匹配
- 用户可上传语音样本，系统识别口音/方言/语速/语调。
- 匹配喜欢同样口音、或想学该方言的用户，促进语音互动。

### 16. 生活习惯极端匹配
- 比如“极度喜欢早起”VS“极度夜猫子”，“极简主义”VS“收藏癖”。
- 匹配生活习惯极端但互不干扰的用户，探索新鲜生活方式。

### 17. 共同完成任务型匹配
- 系统发布“今日任务”或“挑战”，如“互相推荐一本冷门好书”、“一起完成10km步行”。
- 匹配愿意共同完成任务的用户，促进陪伴和互动。

### 18. AI角色扮演辅助匹配
- 用户可选择AI扮演的虚拟身份（如“人生导师”、“吐槽搭子”、“灵魂画手”）。
- 匹配时系统为双方分配或推荐不同AI角色，增加互动趣味和话题引导。

### 19. 梦想/理想国共建匹配
- 用户描绘自己理想的生活场景或“理想国”。
- 匹配描绘相似或互补理想场景的用户，一起畅想未来。

### 20. 反向缘分匹配
- 系统自动识别用户本不可能相遇的概率极小的“反向缘分”（如两人出生地相隔万里、生活圈完全无交集）。
- 推荐“最不可能遇见的人”，让缘分更有戏剧性。
