# 数据库初始化服务实施任务清单

## 目标
- 支持多环境下数据库结构和默认数据的自动初始化。
- 初始化模式、数据来源、是否加载默认数据等全部由配置/环境变量驱动。
- 工厂+注册表+适配器模式，便于扩展和维护。
- 初始化流程自动化、幂等、可重入。

---

## 任务分解

### 1. 配置与环境变量
- [x] 新增并同步声明初始化相关环境变量（NEXT_PUBLIC_DB_INIT_MODE、NEXT_PUBLIC_DB_INIT_SOURCE等）。
- [x] config-keys.ts、config-types.ts、.env.example、文档同步。
- [ ] ConfigService 类型安全读取。

### 2. 初始化模式支持
- [x] 新增 DbInitMode 枚举，统一管理初始化模式。
- [ ] 支持 schema/json/memory/sql 多种初始化方式。
- [ ] 适配环境变量/配置自动切换模式。

### 3. 工厂与适配器注册表
- [ ] 实现 DataInitializerFactory，按配置自动选择适配器。
- [ ] 适配器注册表，支持扩展新类型。

### 4. 适配器实现
- [ ] schema-adapter：ORM/schema 建表，表为空时自动导入 defaultData。
- [ ] json-adapter：批量导入 json，支持清空/幂等导入。
- [ ] memory-adapter：导入 mock-data。
- [ ] sql-adapter：自动遍历执行 SQL 脚本。
- [ ] 适配器支持“仅初始化结构”与“结构+默认数据”两种模式。

### 5. 初始化主流程
- [ ] DataInitializerService 统一封装初始化流程。
- [ ] 冷启动自动检测/初始化。
- [ ] 初始化后可自动触发云端同步。
- [ ] 支持多表、部分表、全量表初始化。

### 6. 幂等性与可重入
- [ ] 初始化逻辑幂等（重复执行不影响数据一致性）。
- [ ] 检查表是否已存在/是否为空，避免重复插入。
- [ ] 支持“重置数据”与“增量导入”两种模式。

### 7. 文档与测试
- [ ] 补充开发/使用文档。
- [ ] 单元测试和集成测试，覆盖各模式和数据源。
